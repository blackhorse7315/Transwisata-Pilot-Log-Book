TRANSWISATA PILOT LOGBOOK — PWA

Upload ALL these files into the SAME GitHub Pages folder:
index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, transwisata-logo.jpg

1. Replace the existing index.html, keeping your GitHub Pages repository path unchanged.
2. Publish and wait for GitHub Pages deployment.
3. Open the HTTPS URL in Chrome Android > three dots > Install app / Add to Home screen.
4. For iPhone Safari: Share > Add to Home Screen.

Firebase remains the ONLY data source. An internet connection is needed to sign in, load and save records. The service worker only caches the app shell and images.
PWA installability requires HTTPS and browser support.
